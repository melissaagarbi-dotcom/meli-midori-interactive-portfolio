# Meli Midori — Interactive Artist Portfolio

An experimental web portfolio combining music, film, photography, and interactive 3D design. I developed the creative direction, interaction system, visual logic, and product requirements, then iterated through implementation using AI-assisted development and deployed the finished experience to the web.

## Live Site

[View the live portfolio](https://melissagarbi.com)

## Concept

I wanted the portfolio itself to behave like part of the artwork rather than a conventional gallery. The cube became a modular interface for music, video, photography, and interactive visual experiments.

## My Role

I conceived the project, defined the visual and interaction system, directed the UX and creative behavior, selected and organized media, tested iterations, diagnosed issues, and guided the implementation through deployment.

Development was completed through an AI-assisted coding workflow rather than a traditional hand-coded software engineering process.

## Creative Direction

The project combines music, film, photography, motion, and interactive web design into a single visual system intended to feel exploratory rather than linear.

## Interaction & Product Design

I defined how the cube should behave, how media appears across faces and tiles, how visual states change, and how users navigate between different creative materials.

## Technical Approach

The project uses:

- Three.js
- Vite
- JavaScript
- WebGL
- IndexedDB
- Vercel
- Responsive Web Design
- AI-assisted development

## Selected Features

- Interactive 3D cube interface
- Per-tile image and video media
- Adjustable transforms and visual effects
- Responsive interaction behavior
- Persistent saved states
- Custom editor workflow
- Multimedia integration across music, film, and photography

## Process

The project was developed iteratively through visual prototyping, interaction testing, debugging, and deployment. I directed the creative and functional behavior while using AI-assisted development to implement and refine the experience.
